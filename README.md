# 合同金额打码工具

把合同 PDF 中的金额（小写数字、¥/￥符号、中文大写金额）自动识别并**真删除式打码**（黑色/白色/灰色矩形覆盖 + 底层文字清除 + 区域内图像像素化），带可视化界面，支持逐页预览复核与手动补打码。

## 一、文件结构

| 文件 | 作用 |
|---|---|
| `miwen_gui.py` | 可视化主程序（**日常用这个**） |
| `redact_engine.py` | 识别 + 打码引擎（界面调用它，也可命令行批量跑） |
| `ai_filter.py` | AI 复核模块（可选）：调千问 API 对识别结果二次筛选 |
| `config.json` | 首次使用「AI 设置」保存后自动生成（含 API Key，**注意保密**） |
| `miwen.py` | 最早期的纯命令行脚本（保留备用，功能已被上面几个覆盖） |
| `tessdata/` | OCR 中英文语言包（`chi_sim.traineddata` + `eng.traineddata`），换电脑整个文件夹拷走即可 |

## 二、环境要求与安装

### 1. Python

- **Python 3.10 及以上**（开发验证于 3.14；Tkinter 图形界面需随 Python 一起安装，官方 Windows 安装包默认勾选）
- 检查：`python --version`

### 2. 依赖库

```bash
pip install pymupdf pillow            # 必装：文字版合同 + 界面
pip install pytesseract               # 可选：扫描版合同自动 OCR 才需要
```

- `pymupdf`：PDF 渲染 / 文字层读取 / 真删除打码（核心）
- `pillow`：预览图显示与 OCR 图像预处理
- `pytesseract`：仅扫描件 OCR 用到，纯文字版合同可不装

> 注意：`pymupdf` 导入名为 `fitz`（旧名）或 `pymupdf`，两者皆可。

### 3. OCR（可选，处理扫描版合同才需要）

扫描版 PDF 没有文字层，需要系统安装 Tesseract OCR 才能自动识别：

1. 用 winget 安装（管理员授权弹窗点"是"）：
   ```bash
   winget install -e --id UB-Mannheim.TesseractOCR --source winget
   ```
2. 中文语言包：把 `chi_sim.traineddata` 放到本目录的 `tessdata/` 文件夹即可（本项目已带好，程序自动加载；也可放系统安装目录 `C:\Program Files\Tesseract-OCR\tessdata\`）。
3. 没装 tesseract 也能用：程序会在启动时提示，扫描件页面用**拖框手动补打码**完成。

### 4. 启动

```bash
python miwen_gui.py
```

## 三、用户使用手册

### 界面总览

- **左侧上**：文件列表（可添加多个 PDF；`✔ n 处`=已识别，`*`=含手动编辑，`·`=未识别。单击切换复核对象，双击未识别文件立即识别）
- **左侧下**：当前文件的待打码条目清单（✓=将打码，—=停用；双击行切换，选中可删除）
- **中间**：PDF 预览，蓝框标注将被打码的区域
- **右侧**：手动添加密文（按文字 / 按坐标）
- **顶部工具栏**：打码颜色（黑/白/灰）、「宁可多遮」开关、**「识别当前」「批量识别」「识别后自动AI复核」开关、「AI复核当前」「AI设置」「批量导出」**

> **重要**：每个文件的识别结果、手动补充、停用/删除都是**独立保存**的——批量识别后可以随意来回切换文件逐个检查，任何文件的编辑都不会丢失。

### 标准流程（批量）

1. **添加 PDF**（可一次多选）→ 点 **「批量识别」**，引擎逐个扫描所有文件的金额，进度显示在底部状态栏；已识别过的文件会自动跳过，不会覆盖你的编辑
2. **逐个复核**：在左侧文件列表点选某个文件 → 预览区翻页/缩放检查蓝框位置
   - **漏掉的金额** → 在预览图上**按住鼠标拖一个方框**圈住 → 确认 → 立即加入清单并生效
   - **不想打的条目** → 双击该行变「—」停用（比如误遮的编号、日期）
   - **删掉不需要的条目** → 选中后点「删除选中条目」
   - 手动添加还有两种方式（右侧面板）：**按文字添加**（输入原文，全文匹配处一次加入）、**按区域添加**（拖框后坐标自动填入，可微调再提交）
3. 复核完切换到下一个文件继续（上一步的编辑已保留），全部检查完后点 **「批量导出」** → 选输出目录 → 一次性按「原名称密文.pdf」输出**全部文件**，每个文件用的是它自己清单里**启用状态**的条目（含各自的手动补充与停用）
4. 只想单独处理一个文件时：选中它 → 「识别当前」→ 复核 → 右下角 **「另存为『原名称密文.pdf』」** 自选保存位置

### AI 复核（可选，第二重保险）

本地规则识别之后，可以再让**千问大模型**过一遍候选清单，专门解决两类问题：

- **排除误报**：电话号码、设备型号/序列号、身份证/统一社会信用代码、银行账号、日期、数量单位、百分比、页码条款号等被规则误标的数字 → AI 判定后自动**停用不打码**（清单里来源列显示 `AI排除·原因`，双击可人工改回）
- **补充漏报**：从页面文本里找规则没盖住的金额/中文大写金额 → 自动定位并加入打码清单（来源 `AI补充`）

**怎么用：**

1. 申请 Key：登录 [阿里云百炼控制台](https://bailian.console.aliyun.com)（新用户有免费额度），获取 `sk-` 开头的 DASHSCOPE_API_KEY
2. 界面点 **「AI设置」** → 填入 Key、选模型（默认 qwen-plus，可选 qwen-turbo 更快更省 / qwen-max 更准）→ 可先「测试连接」→ 保存
3. 三种触发方式：
   - 点 **「AI复核当前」**：只复核当前打开的文件
   - 勾选 **「识别后自动AI复核」**：之后每次「识别当前 / 批量识别」完成后，自动对本次新识别的全部文件接力复核
   - Key 也可写进环境变量 `DASHSCOPE_API_KEY`（程序优先读环境变量）

**注意：**

- 开启 AI 复核会把**涉及候选项的页面纯文本发送到云端**（只发文本、不发原始文件；手动条目不会被 AI 改动）——合同内容敏感时请自行评估
- 按 token 计费；10 页合同复核一次大约几千 token，量级很小但非免费
- 未配置 Key 时整个功能完全不影响使用，程序仍可全程离线运行
- AI 判断也可能出错，**批量导出前仍以人工复核预览为准**

### 缩放与翻页

| 操作 | 效果 |
|---|---|
| **Ctrl + 鼠标滚轮** | 以鼠标位置为中心放大 / 缩小预览 |
| 鼠标滚轮（不按 Ctrl） | 上下滚动页面 |
| 「缩小 / 放大」按钮 | 每档 ±0.3 倍 |
| 「◀ 上一页 / 下一页 ▶」 | 翻页 |
| 双击清单条目 | 切换该条打码开关 |
| 双击文件列表条目 | 未识别则立即识别该文件 |

### 打码颜色怎么选

- **黑色**（默认）：常规遮盖，输出文件最小
- **白色**：需要"看起来像没印字"的场合（如扫描件补白）
- **灰色**：介于两者之间
- 三种都是**真删除**：底层文字被清除、区域内图像被像素化，复制/搜索/拆开图层都取不回来

## 四、自动识别规则（引擎逻辑）

识别走"文字层优先、OCR 兜底"两条路：

**文字层页面**（Word 转 PDF、电子签章件）——按行 + 文字块坐标匹配：

| 类型 | 示例 | 来源标记 |
|---|---|---|
| 关键词 + 数字金额（同行） | `合同金额：128,000.00` `单价 3500` | 自动 |
| 关键词在上行、金额在下行（表格） | `合计金额`↵`256,000.00` | 自动 |
| ¥/￥ 符号金额 | `¥99,999.99` | 自动 |
| 数字 + 元/万元 | `8,600.00 元` | 自动 |
| **中文大写金额** | `人民币捌拾贰万伍仟元整`（**直接打码**，含 OCR 错字揽/什/佰等兼容） | 自动 |
| 关键词行（同行有金额迹象） | 从关键词起遮到**整行右端** | 关键词 |
| 裸数字（勾选「宁可多遮」后） | `825000` `32.5` | 激进 |

**无文字层页面**（扫描件/图片页）：自动走 Tesseract OCR（中+英），识别失败的页面保持原样并提示手动框选。

匹配前会把文本**去掉空格**再比对，因此 Word 里中英文字体切换拆成多段、OCR 结果字间有空格等情况都不影响识别。

## 五、常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 大写金额没被识别 | 已是本次修复重点；若个别字被 OCR 认成集合外怪字，用拖框补上即可 |
| 拖框后位置不对 | 已修复（旧版放大/滚动后偏移）；请确认用的是最新版 `miwen_gui.py` |
| 保存时提示占用/失败 | 目标文件正被阅读器打开，换个文件名或先关闭 |
| 启动提示"未检测到 tesseract" | 只影响扫描件自动识别，文字版合同不受影响 |
| 想识别更多关键词 | 编辑 `redact_engine.py` 顶部 `KEYWORDS` 列表，加中文关键词即可 |
| 批量处理很慢 | OCR 每页约 1 秒属正常；确认打开「宁可多遮」会生成更多候选条目但不会更慢 |
| AI 复核提示 401 / Key 无效 | Key 粘贴不完整或已过期，重新到百炼控制台复制；注意保存后走环境变量优先 |
| AI 把该遮的金额排除了 | AI 判断非 100% 可靠，清单里找到那条 `AI排除·…`，双击改回 ✓ 即可 |
| 没配 Key 能不能用 | 能。AI 复核是可选层，本地规则识别 + 手动补打完全离线可用 |

## 六、命令行批量（可选，无界面）

```bash
python redact_engine.py "D:\合同\a.pdf" "D:\合同\b.pdf"
```

在同目录输出 `a密文.pdf`、`b密文.pdf`，使用默认识别规则（含激进裸数字）。

## 安全提示

- 打码是**不可逆**操作：确认预览无误再另存；原始合同请自行保留备份
- 本工具全程离线运行，合同文件不会上传任何外部服务
- 代码全由ai生成，部分bug不影响实际使用
